# ClickPlan — Roadmap

## v1.0 — Foundation (current)

- [x] Onboarding (pen setup + calibration prompt)
- [x] Home screen with this week's target clicks
- [x] Fullscreen click counting with microphone
- [x] Vibration feedback at target
- [x] Save dose (subtracts from remaining clicks)
- [x] Pen remaining clicks tracking
- [x] Injection history log
- [x] Manual +1 / −1 correction during counting
- [x] German / English text resources
- [x] Calibration (noise baseline + click peak detection)

## v1.1 — Pen lifecycle

- [ ] Pen end reconciliation: expected vs actual clicks
- [ ] "Mark pen empty" flow when physical stop is reached
- [ ] App adjusts remaining clicks calmly: "Pen completed."
- [ ] New pen flow: reset clicks, optional re-measure

## v1.2 — Reduction assistant

- [ ] At new pen only: keep dose or reduce one step
- [ ] No mid-pen dose changes enforced by UI
- [ ] Dose history per pen (not just per injection)

## v2.0 — Smart mode (optional)

- [ ] Gradually find the lowest user-tolerated long-term dose
- [ ] Still minimal UI — no extra screens
- [ ] User opts in explicitly

## Not planned

- Cloud sync
- User accounts
- Weight / BMI / calorie tracking
- Food noise tracking
- Gamification or badges
- Community features
- Medical recommendations
