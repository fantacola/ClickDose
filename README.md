# ClickDose Premium v3.4

Native Android MVP for click-based Multipen dose setting.

## Neu in v3.4
- eigener Fullscreen-Zählmodus
- großer Live-Counter `count / target`
- segmentierter Ring läuft während des Drehens live bis zum Ziel
- Dosis speichern zieht die gezählten Klicks vom Pen-Rest ab
- Homescreen ist ruhiger und zeigt nur Tagesziel + Pen-Rest
- Volldosis-Messung bleibt unter Mehr verfügbar

Neu: ClickDose Branding, lokales Protokoll und Sprachumschaltung DE/EN.

Technisch/rechnerisch, keine medizinische Empfehlung.
